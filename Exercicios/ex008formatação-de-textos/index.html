Principais formatações

Negrito / Destaque

Nessa frase temos temos um termo em negrito utilizando a tag <b> (não semântica).

Nesta frase temos um termo em destaque utilizando a tag <strong> (semântica).

Itálico / Ênfase

Nesta frase, temos um termo em itálico utilizando a tag <i> (não semântica).

Nesta frase temos um termo em ênfase utilizando a tag <em> (semântica).

Texto marcado

podemos criar tambem um texto marcado utilizando a tag <mark>.

posso mudar a cor da marcação utilizando o código style="background-color:alguma cor" dentro da tag <mark>.

Texto deletado

Podemos marcar um texto excluído, utilizando a tag <del> para indicar que ele deve ser lido mas não considerado.

Texto inserido

Podemos marcar um texto como inserido, utilizando a tag <ins>, para dar uma ênfase e indicar que ele foi adicionado depois.

Texto sobrescrito

Para inserir coisas do tipo x20+3, você pode usar a tag <sup>.

Texto subscrito

Para inserir coisas do tipo H2O, você pode usar a tag<sub>
